# Needlbar v0.2.1 Widgets and Notifications Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the user-approved v0.2.1 native medium Overview widget and opt-in, local, app-running-only Claude/Codex quota notifications without changing provider integrations, Rust/C ABI, authentication, or the v0.2.0 export contract.

**Architecture:** The main Needlbar app remains the sole provider-fetching process and maps its actor-owned snapshots into a sanitized, versioned local projection in the App Group. A separately built and embedded WidgetKit extension reads only that projection; a serialized notification evaluator runs only in the live main app and uses a durable local de-duplication ledger. The widget and notification work are kept in separate subplans and executed sequentially to avoid concurrent edits to shared AppDelegate, Settings, and packaging surfaces.

**Tech Stack:** Swift 6, SwiftUI, AppKit, WidgetKit, UserNotifications, App Group shared storage, Foundation, existing SwiftPM/Rust build, test, packaging, and smoke scripts, and macOS 14 arm64 acceptance.
