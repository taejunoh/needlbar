# Needlbar v0.2.1 Native Acceptance Driver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a separately signed, fixture-driven macOS 14 acceptance artifact that deterministically exercises the existing widget-projection and quota-notification paths without adding a fixture capability to normal or public Needlbar builds.

**Architecture:** `NEEDLBAR_ACCEPTANCE_DRIVER` gates all driver source at compilation. The acceptance executable parses one external, bounded fixture before `AppDelegate` starts services; it then applies the fixture’s fixed sanitized values through `ProviderSnapshotStore` while the existing `WidgetProjectionPublisher`/`WidgetCenter` path and `QuotaNotificationService`/`QuotaAlertLedgerStore`/`UNUserNotificationCenter` path run unchanged. Production packaging stays featureless and is checked structurally; a distinct, non-notarized Developer-ID-signed acceptance bundle is used only in a disposable macOS 14 arm64 account/VM.

**Tech Stack:** Swift 6, Swift Testing, Foundation, AppKit, WidgetKit, UserNotifications, App Groups, existing atomic file writer and notification ledger, Bash, Developer ID code signing, macOS 14 arm64.

## Invariants Used by Every Task

- Use only `--acceptance-fixture <absolute-path>` as the acceptance launch spelling. It must be the entire post-executable argument list and appears only in an acceptance-compiled host.
- The parser accepts UTF-8 JSON only, at most 256 KiB, with at most 32 events and delays in `0...900`. It rejects duplicate and unknown keys before domain conversion.
- The only stable parser codes are `fixturePathInvalid`, `fixtureReadFailed`, `fixtureTooLarge`, `fixtureMalformedJSON`, `fixtureUnknownKey`, `fixtureDuplicateKey`, `fixtureInvalidValue`, `fixtureUnknownID`, and `fixtureCanaryDetected`. Rendering is exactly `<code>` or `<code>: event <zero-based-index>`; it never includes a path, bytes, field value, or parser diagnostic.
- The fixture contains canonical test values only. It never contains provider payloads, account data, credentials, URLs, paths, raw window titles, source content, messages, diagnostics, prompts, or responses. Treat these case-insensitive canaries as `fixtureCanaryDetected`: `access_token`, `refresh_token`, `secret`, `password`, `cookie`, `authorization`, `apikey`, `api_key`, `bearer`, `keychain`, `http://`, `https://`, `/users/`, `/private/`, `prompt`, `response`, `source`, `repository`, and `file://`. The required schema key `tokens` is an aggregate count, not a credential canary.
- The extension stays exactly the production extension: no `Acceptance`, fixture, `NeedlbarCore`, `CNeedlbar`, Rust, Keychain, URLSession, provider, or network dependency is added to it.
- No task pushes, tags, notarizes, uploads, changes Apple-portal state, handles credentials, or changes the public v0.2.2 release record.
- Build and Developer-ID-sign the acceptance bundle only on the trusted build host that already has the configured signing identity in its Keychain. Transfer that completed bundle read-only to the macOS 14 guest; never copy an identity, certificate, keychain, password, or signing credential to the guest. All guest inputs and evidence remain beneath explicit `/Users/taejunoh/Developer/LFG` paths, then sanitized evidence is copied back beneath the trusted host’s `/Users/taejunoh/Developer/LFG` evidence root.

- [ ] **Step 4: Implement the strict acceptance-only parser and fixture domain.**

  Create `Sources/Needlbar/Acceptance/AcceptanceFixture.swift`. Wrap the entire file in `#if NEEDLBAR_ACCEPTANCE_DRIVER` / `#endif`; do not leave a public-build declaration, literal launch argument, fixture resource lookup, or fallback parser outside that condition. Use the following public-to-the-target contract exactly:

  ```swift
  #if NEEDLBAR_ACCEPTANCE_DRIVER
  import Foundation
  import NeedlbarCore

  public enum AcceptanceFixtureErrorCode: String, Sendable {
      case fixturePathInvalid, fixtureReadFailed, fixtureTooLarge, fixtureMalformedJSON
      case fixtureUnknownKey, fixtureDuplicateKey, fixtureInvalidValue, fixtureUnknownID, fixtureCanaryDetected
  }

  public struct AcceptanceFixtureFailure: Error, Sendable, Equatable, CustomStringConvertible {
      public let code: AcceptanceFixtureErrorCode
      public let eventIndex: Int?
      public static let fixturePathInvalid = AcceptanceFixtureFailure(code: .fixturePathInvalid, eventIndex: nil)
      public var description: String { eventIndex.map { "\(code.rawValue): event \($0)" } ?? code.rawValue }
  }

  public struct AcceptanceFixture: Sendable {
      public static let maximumBytes = 256 * 1024
      public static let maximumEvents = 32
      let timeZone: TimeZone
      let startAt: Date
      let events: [AcceptanceFixtureEvent]
  }

  struct AcceptanceFixtureEvent: Sendable {
      let delay: Duration
      let localDay: String
      let usage: [ProviderID: UsageSnapshot]
      let quota: [ProviderID: QuotaSnapshot]
      let eventDate: Date
  }

  enum AcceptanceFixturePath {
      static func validate(_ path: URL, beneath root: URL, fileManager: FileManager = .default) throws -> URL {
          guard path.isFileURL, root.isFileURL, path.path.hasPrefix("/") else { throw AcceptanceFixtureFailure.fixturePathInvalid }
          let canonicalRoot = root.resolvingSymlinksInPath().standardizedFileURL
          let canonicalPath = path.resolvingSymlinksInPath().standardizedFileURL
          guard canonicalPath.path.hasPrefix(canonicalRoot.path + "/"),
                (try? canonicalPath.resourceValues(forKeys: [.isRegularFileKey]).isRegularFile) == true else {
              throw AcceptanceFixtureFailure.fixturePathInvalid
          }
          return canonicalPath
      }
  }

  enum AcceptanceFixtureParser {
      static func readAndParse(path: URL, beneath root: URL) throws -> AcceptanceFixture {
          let file = try AcceptanceFixturePath.validate(path, beneath: root)
          guard let bytes = try? Data(contentsOf: file, options: [.mappedIfSafe]), !bytes.isEmpty else {
              throw AcceptanceFixtureFailure(code: .fixtureReadFailed, eventIndex: nil)
          }
          guard bytes.count <= AcceptanceFixture.maximumBytes else {
              throw AcceptanceFixtureFailure(code: .fixtureTooLarge, eventIndex: nil)
          }
          return try parse(data: bytes)
      }

      static func parse(data: Data) throws -> AcceptanceFixture {
          guard data.count <= AcceptanceFixture.maximumBytes else { throw AcceptanceFixtureFailure(code: .fixtureTooLarge, eventIndex: nil) }
          guard let source = String(data: data, encoding: .utf8), !source.unicodeScalars.contains(where: { $0.value < 0x20 && $0 != "\n" && $0 != "\r" && $0 != "\t" }) else {
              throw AcceptanceFixtureFailure(code: .fixtureMalformedJSON, eventIndex: nil)
          }
          let root = try AcceptanceJSONScanner.parseObject(source)
          try AcceptanceFixtureValidation.rejectCanaries(in: root, eventIndex: nil)
          return try AcceptanceFixtureValidation.fixture(from: root)
      }
  }
  #endif
  ```

  Implement `AcceptanceJSONScanner.parseObject(_:)` as the single one-pass UTF-8 scan: it parses the complete document, tracks each object’s key set at the moment it reads a key, and throws `.fixtureDuplicateKey` before accepting a duplicate. It must parse strings with JSON escapes, arrays, integer and decimal JSON numbers, `true`, `false`, and `null`; reject a trailing token, an invalid escape, unclosed string/container, or invalid number as `.fixtureMalformedJSON`. It returns only `[String: AcceptanceJSONValue]`, `[AcceptanceJSONValue]`, `String`, `Decimal`, `Bool`, and `nil` values, so validation never needs `JSONSerialization` or `JSONDecoder` duplicate-key behavior.

  Implement validation exactly as follows:

  ```swift
  private enum AcceptanceFixtureValidation {
      static let rootKeys: Set<String> = ["schemaVersion", "timeZone", "startAt", "events"]
      static let eventKeys: Set<String> = ["delaySeconds", "localDay", "usage", "quota"]
      static let usageKeys: Set<String> = ["tokens", "costUSD"]
      static let quotaKeys: Set<String> = ["id", "remainingPercent", "resetsAt"]
      static let quotaIDs: [ProviderID: Set<String>] = [
          .claude: ["claude.session", "claude.weekly"],
          .codex: ["codex.primary", "codex.secondary"],
      ]

      static func fixture(from root: [String: AcceptanceJSONValue]) throws -> AcceptanceFixture
      static func rejectCanaries(in value: AcceptanceJSONValue, eventIndex: Int?) throws
  }
  ```

  `fixture(from:)` must require the exact root/event/value key sets (never a subset with an unknown key), `schemaVersion == 1`, an IANA `TimeZone`, RFC 3339 fractional-second dates, a canonical `yyyy-MM-dd` local day in the supplied zone, and an event date equal to `startAt + cumulative delay`. It must reject event counts above 32, delay values that are not finite integers in `0...900`, future `startAt`/event timestamps relative to `Date()`, negative or overflowing tokens, invalid/negative/noncanonical decimals, nonfinite or out-of-range percentages, duplicate provider rows, duplicate quota IDs, Cursor quotas, and a provider/window mismatch. It must set a failure’s `eventIndex` for an event/usage/quota-row error and `nil` for path/read/root errors. Build usage as a `UsageSnapshot` whose all-period totals equal `tokens`, whose `last7DaysDaily` is exactly the event’s `localDay`, and whose cost is the accepted decimal; build `QuotaWindow` with fixed title `"Session"`, `"Weekly"`, `"Primary"`, or `"Secondary"` selected solely from the allowlisted ID and `usedPercent: 100 - remainingPercent`.

          let store = store
          let sleeper = sleeper

          await task?.value
          task = nil

          task = nil
          running?.cancel()
          await running?.value

              timeZoneIdentifier: timeZone.identifier,
              utcOffsetSeconds: timeZone.secondsFromGMT(for: event.eventDate)
