# Needlbar v0.2.0 Local JSON Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Settings-only, user-initiated local JSON export of one immutable normalized Needlbar snapshot for automation and backup.

**Architecture:** `ProviderSnapshotStore` creates one actor-isolated `ExportCapture` for Claude, Codex, and Cursor. `NeedlbarCore` validates and deterministically encodes that capture, then commits its bytes through a same-directory, private atomic writer. `NeedlbarApp` owns only the save panel and fixed UI states, passing the already-captured value and exact confirmed URL to the Core export action.

**Tech Stack:** Swift 6, Foundation, AppKit `NSSavePanel`, SwiftUI, Swift Testing, Darwin POSIX file APIs, SwiftPM, and the existing `make test`/package/smoke verification path.

**Spec:** `docs/superpowers/specs/2026-08-29-needlbar-v0.2.0-local-json-export-design.md`

## Global Constraints

- Implement only v0.2.0 local JSON export. v0.2.1 owns widgets/notifications; v0.2.2 owns project, commit, and pull-request analytics.
- Settings is the only export entry point. It exposes one JSON-only `Export snapshot…` action; there is no Overview action, shortcut, format selector, background/scheduled export, cloud sync, telemetry, or history database.
- Capture exactly once, immediately through `ProviderSnapshotStore`, before presenting the save panel. Capture must not refresh, authenticate, access Keychain, perform network or Rust/C ABI work, or reread the store during encoding.
- The capture and export always include exactly `claude`, `codex`, `cursor` in that order, independent of enabled modules, visible UI, data availability, or refresh result.
- The v1 document has `schemaVersion: 1`, UTC millisecond RFC3339 timestamps, sorted object keys, and exactly one trailing newline.
- Usage includes `allTime`, `today`, `last7Days`, `last30Days`, and `last7DaysDaily`; all token counters and costs are canonical non-negative decimal strings. `allTime` maps top-level `UsageSnapshot` counters, not an approximated period.
- Usage/quota streams are independent: each has nullable `data` and a status containing only `state`, `lastSuccessfulAt`, and `errorCode`. States are `fresh`, `stale`, `unavailable`, `requiresAuthentication`, and `error`; only `error` uses `refreshFailed`.
- Quota windows serialize only allowlisted stable IDs (`claude.session`, `claude.weekly`, `codex.primary`, `codex.secondary`), `usedPercent`, and `resetsAt`; titles never export. Cursor quota data is always `null`.
- Never export secrets, credentials, cookies, account IDs, raw paths, provider/raw diagnostic messages or responses, prompts, responses, source code, or source-content-derived text.
- Validate and encode before creating a file. Write only via a randomized sibling temporary file with exclusive creation and `0600`, `fchmod(0600)`, full write, file `fsync`, atomic rename, then parent-directory `fsync`. Do not directly write the destination, copy/delete across volumes, or fall back from rename.
- Pre-rename failures preserve an existing destination. Attempt to remove only the exact temporary file; a failed cleanup remains an internal recoverable condition and never triggers broad cleanup. Any parent-directory open, `fsync`, or close failure after rename is committed success with an internal durability warning.
- `NeedlbarApp` configures `NSSavePanel` with `.json`, rejects non-file/non-JSON fake-presenter URLs without invoking Core, preserves the exact confirmed URL, disables the action in flight, leaves cancellation unchanged, and shows only `Exported` or `Could not export snapshot.`
- Do not change Rust, the C ABI, provider data/authentication boundaries, `tokscale-core`, deployment targets, or release/tag state. Cursor remains local-cache usage plus the provider Spending dashboard action.
- Keep the v0.1 release gate separate. No tag or release action is authorized.

- [ ] **Step 3: Implement the operation seam, writer, and Core export action**

Define the writer interfaces and a narrow POSIX seam similar to:

```swift
public protocol SnapshotFileWriter: Sendable {
    func writeAtomically(_ bytes: Data, to destination: URL) throws -> AtomicWriteResult
}

public enum AtomicWriteResult: Sendable, Equatable {
    case committed
    case committedWithDurabilityWarning
}

public protocol CoreExportAction: Sendable {
    func export(_ capture: ExportCapture, to destination: URL) async throws -> AtomicWriteResult
}

public struct DefaultCoreExportAction: CoreExportAction {
    private let exporter: SnapshotExporter
    private let writer: any SnapshotFileWriter

    public init(
        exporter: SnapshotExporter = SnapshotExporter(),
        writer: any SnapshotFileWriter = POSIXSnapshotFileWriter()
    ) {
        self.exporter = exporter
        self.writer = writer
    }

    public func export(_ capture: ExportCapture, to destination: URL) async throws -> AtomicWriteResult {
        let bytes = try exporter.encode(capture)
        return try await Task.detached { [writer] in
            try writer.writeAtomically(bytes, to: destination)
        }.value
    }
}
```

`POSIXSnapshotFileWriter` must expose `public init()` for production composition, require `destination.isFileURL`, derive the temporary path from `destination.deletingLastPathComponent()` and a UUID, and open it with `O_CREAT | O_EXCL | O_WRONLY` and `0600`. It calls `fchmod(0600)`, loops until all bytes are written, `fsync`s and closes the temporary descriptor, then calls one `rename(temp, destination)` as the commit point. After rename, attempt to open the same parent as a directory, `fsync` it, and close it. Any failure in those post-rename parent operations returns `.committedWithDurabilityWarning`; no post-commit failure may be surfaced as a failed replacement.

Before rename, defer cleanup of only the exact temporary path. Do not delete the destination, recursively inspect a directory, substitute a cross-directory path, copy bytes to the destination, or include a path/system string in `SnapshotFileWriteError`. The concrete operations must retry interrupted POSIX calls where required and close descriptors on every path.

Create `SnapshotExportController.swift` with AppKit/UniformTypeIdentifiers imports and these core behaviors:

```swift
@MainActor
public protocol SavePanelPresenter: AnyObject {
    func selectDestination(defaultFilename: String) -> URL?
}

@MainActor
public final class SnapshotExportController: ObservableObject {
    @Published public private(set) var state: SnapshotExportState = .idle
    public var isExporting: Bool { state == .exporting }

    public func exportSnapshot() {
        guard !isExporting else { return }
        let priorState = state
        state = .exporting
        let exportedAt = captureClock()
        Task { [captureSource, savePanelPresenter, coreExportAction] in
            let capture = await captureSource.captureForExport(exportedAt: exportedAt)
            guard let destination = savePanelPresenter.selectDestination(defaultFilename: Self.filename(for: exportedAt)) else {
                state = priorState
                return
            }
            guard destination.isFileURL, destination.pathExtension.lowercased() == "json" else {
                state = .failed
                return
            }
            do {
                _ = try await coreExportAction.export(capture, to: destination)
                state = .exported
            } catch {
                state = .failed
            }
        }
    }
}
```

`NSSavePanelPresenter` must configure `allowedContentTypes = [.json]`, `allowsOtherFileTypes = false`, and `nameFieldStringValue` before `runModal()`. Return the panel URL unchanged only when the panel confirms; never normalize, alter, or synthesize the selected URL. The controller owns only `idle`/`exporting`/`exported`/`failed`; `SettingsView` maps `.exported` to `Exported` and `.failed` to `Could not export snapshot.` with no path/system detail.
