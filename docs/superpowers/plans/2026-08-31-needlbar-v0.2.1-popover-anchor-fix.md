# Needlbar v0.2.1 Popover Anchor Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Anchor the existing Needlbar `NSPopover` to the visual bottom of the clicked menu-bar button on both flipped and non-flipped coordinate systems.

**Architecture:** Keep the existing `NSPopover`, status-item abstraction, transient behavior, and global outside-click fallback. Add one pure edge-selection helper and make `AppKitStatusItemHandle` select `.maxY` for flipped views and `.minY` for non-flipped views; do not introduce screen coordinates, offsets, activation changes, or a custom panel.

**Tech Stack:** Swift 6, AppKit `NSPopover`/`NSStatusBarButton`, Swift Testing, existing SwiftPM/Rust package pipeline, Developer ID local signing.
