# Needlbar v0.3.0 Release and Homebrew Cask Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release the completed v0.3.0 build through the existing signed pipeline, then add one SHA-pinned, arm64-only Homebrew Cask for the verified public ZIP.

**Architecture:** Current release assertions move to v0.3.0 while a distinct historical fixture protects the v0.2.2 release record. The tagless and tag-triggered workflow runs independently build and verify their own artifacts. The Cask consumes only the later, freshly downloaded public asset.

**Tech Stack:** SwiftPM 6, Cargo, Bash 3.2, Ruby shell-test fixtures, GitHub Actions/CLI, macOS signing tools, and Homebrew Cask.

- [ ] **Step 2: Create the one-file Cask**

Generate the exact source from the measured checksum, inspect stdout, then add
that source with `apply_patch`. This generator writes no file and invents no
checksum. The single-quoted heredoc preserves Cask's version interpolation.

```bash
RELEASE_SHA="$release_sha" ruby <<'RUBY'
sha = ENV.fetch('RELEASE_SHA')
abort 'invalid public digest' unless sha.match?(/\A[0-9a-f]{64}\z/)
source = <<~'CASK'
cask "needlbar" do
  version "0.3.0"
  sha256 PUBLIC_DIGEST

  url "https://github.com/taejunoh/needlbar/releases/download/v#{version}/Needlbar-macos-arm64.zip"
  name "Needlbar"
  desc "Menu-bar monitor for AI usage and system health"
  homepage "https://github.com/taejunoh/needlbar"

  depends_on macos: :sonoma
  depends_on arch: :arm64

  app "Needlbar.app"
end
CASK
puts source.sub('PUBLIC_DIGEST', sha.dump)
RUBY
```

The final SHA stanza must be a literal equal to the downloaded public ZIP digest; compare it programmatically with `release_sha` before committing. Do not add `zap`, `trash`, `livecheck`, credentials, automatic tap writes, or updater/appcast metadata. `depends_on arch: :arm64` actively rejects Intel; a URL filename does not. This follows the [Homebrew Cask Cookbook](https://docs.brew.sh/Cask-Cookbook) macOS/architecture dependency guidance.
