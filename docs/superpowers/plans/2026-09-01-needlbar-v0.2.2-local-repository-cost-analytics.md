# Needlbar v0.2.2 Local Repository Cost Analytics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a manual, local-only 30-day Analytics window that attributes existing local AI usage to automatically observed Git repositories and conservatively correlates it to local commits.

**Architecture:** A pinned `tokscale-core` additive report retains workspace/session/model/timing provenance while using its existing streaming and cross-file-dedup path with cached-only pricing. A new Rust `needlbar-project-analytics` crate maps only those observed workspaces to local repositories, runs bounded read-only Git commands, correlates fragments to commits, and emits a sanitized payload through a new bridge symbol. `NeedlbarCore` owns decoded in-memory fresh/stale analytics state; AppKit owns the Overview action and a separate resizable window.

**Tech Stack:** Rust 2021, pinned `tokscale-core`, Tokio process timeout support, Foundation/Swift 6 actors, AppKit `NSWindow`, SwiftUI, Swift Testing, Cargo, SwiftPM, and `make test`.

**Spec:** `docs/superpowers/specs/2026-09-01-needlbar-v0.2.2-local-repository-cost-analytics-design.md`

---

## Global constraints

- The analysis range is exactly the 30 days ending at one bridge-captured UTC `generatedAt`; it runs only when the Analytics window first opens or the user presses its Refresh button.
- Do not add an analytics watcher, timer, launch scan, database, UserDefaults record, App Group file, provider refresh, provider API call, authentication request, Keychain access, remote Git command, forge API call, browser action, telemetry, or export field.
- `tokscale-core` remains the only owner of provider-session parsing, pricing, and cross-file dedup. New consumers must fold through its production streaming path, never through `parse_local_unified_messages`.
- The additive report must use cached-only pricing (`PricingService::load_cached_any_age`) and must not call `PricingService::get_or_init`; absent cached pricing is represented by coverage, not by a network request or invented cost.
- A repository is eligible only when a workspace recovered from an existing supported usage source leads to it. Never enumerate arbitrary directories or inspect a repository solely because it is present on disk.
- The Git helper executes absolute `/usr/bin/git` with fixed argument arrays and no shell. It runs read-only discovery/log commands only; no aliases, hooks, credential helpers, remote commands, fetches, pushes, external diffs, or interactive prompts.
- A raw workspace path, repository root, remote URL, branch, commit message, author/email, full commit OID, session ID, prompt, response, source content, credential, account identifier, stdout, or stderr must not cross from Rust to C/Swift, diagnostics, widgets, notifications, or v0.2.0 export.
- `observedActiveTimeSeconds` means timestamp-derived AI-session activity using the fixed three-minute idle gap. It is not human coding time. Commit cost is labelled `correlated estimated AI cost`, not causal cost. Model metrics are cost/throughput metrics, never a quality or productivity score.
- A fragment ending at `E` maps once to the earliest same-repository local commit with committer time `C` where `E <= C <= E + 4h`; equal times break by full OID. Fragments whose window extends past `generatedAt` are `pendingCommitWindow`.
- A PR number may be emitted only for one unambiguous local `(#<n>)` or `PR #<n>` marker in the commit message (`1...2_147_483_647`). No forge, URL, status, title, author, or PR existence claim is made.
- Keep existing `needlbar.v1` usage/quota ABI, `UsageSnapshot`, export JSON, widget projection, alert ledger/policy, notification behavior, provider auth, Cursor local-only behavior, package metadata, and macOS 14 target unchanged.

pub struct AnalyticsPayload;
pub fn build_analytics_payload(report: WorkspaceSessionReport, generated_at: DateTime<Utc>, git: &dyn GitRunner) -> AnalyticsPayload;
