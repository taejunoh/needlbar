# Needlbar v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native macOS 14+ menu-bar app that shows Claude Code, Codex, and Cursor token usage, estimated cost, quota remaining, and reset times using an embedded Rust usage engine plus independent provider quota adapters.

**Architecture:** Swift/AppKit owns the macOS shell and presentation; `NeedlbarCore` owns normalized state, refresh scheduling, and last-known-good behavior. Rust owns usage aggregation through a pinned standalone `tokscale-core`, Cursor usage-source hydration, provider quota/authentication adapters, and a narrow JSON-over-C ABI. Usage and quota remain independently refreshable and independently fallible.

**Tech Stack:** Swift 6, SwiftUI, AppKit/`NSStatusItem`, Swift Package Manager, Rust 2021 edition, Cargo, `tokscale-core`, `reqwest`, `tokio`, `serde`, C ABI, Swift Testing/XCTest, Rust unit/integration tests, and GitHub Releases. v0.1 ships as a signed/notarized GitHub Release; Sparkle and Homebrew cask integration are deliberately deferred until after the first stable artifact.

## Global Constraints

- macOS 14+ only for v0.1.
- Apple Silicon (`arm64`) is the first supported architecture; do not add Intel-specific work unless universal packaging is proven low-cost after the arm64 artifact passes.
- Supported providers are exactly Claude Code, Codex, and Cursor.
- Default menu-bar configuration is Overview ON, Claude OFF, Codex OFF, Cursor OFF.
- Each menu-bar module supports exactly three title metrics: quota remaining, tokens today, estimated cost today.
- Overview quota means the eligible quota window with the lowest remaining percentage across enabled providers.
- `tokscale-core` owns session discovery, parsing, deduplication, aggregation, pricing, and normalized usage values.
- `needlbar-source-sync` owns Cursor usage-export hydration only; it must not compute subscription quota.
- `needlbar-quota` owns quota retrieval, reset windows, credential discovery/refresh, and provider-specific fallback logic; it must not parse token-history files.
- `needlbar-bridge` owns the stable C ABI, UTF-8 JSON envelopes, panic containment, and memory freeing; no presentation logic belongs there.
- Usage and quota may succeed or fail independently and must never erase one another's valid last-known-good value.
- No Needlbar backend, account system, telemetry, prompt upload, response upload, source-code upload, or source-code display.
- Browser-cookie import is never a silent first-choice path; any Cursor browser-session import must be an explicit user action.
- No notifications, widgets, cloud sync, GitHub/PR integration, project attribution, session browser, or additional providers in v0.1.
- `tokscale-core` is pinned to `Nanako0129/tokscale-core` commit `53f9eefffd3278fd430076531548f7b1f5861f9a` for the first implementation baseline; upgrades require fixture cross-checks before changing the pin.
- The approved design spec at `docs/superpowers/specs/2026-08-13-needlbar-v0.1-design.md` is authoritative when this plan is silent.

- [ ] **Step 2: Implement the typed envelope and safe CString conversion**

Create `envelope.rs`:

```rust
use chrono::{SecondsFormat, Utc};
use serde::Serialize;

pub const SCHEMA_VERSION: &str = "needlbar.v1";

#[derive(Debug, Clone, Serialize)]
pub struct BridgeError {
    #[serde(skip_serializing_if = "Option::is_none")]
    pub provider: Option<String>,
    pub code: String,
    pub message: String,
}

#[derive(Debug, Serialize)]
pub struct Envelope<T: Serialize> {
    #[serde(rename = "schemaVersion")]
    pub schema_version: &'static str,
    pub ok: bool,
    #[serde(rename = "generatedAt")]
    pub generated_at: String,
    pub data: Option<T>,
    pub errors: Vec<BridgeError>,
}

impl<T: Serialize> Envelope<T> {
    pub fn success(data: T) -> Self {
        Self {
            schema_version: SCHEMA_VERSION,
            ok: true,
            generated_at: Utc::now().to_rfc3339_opts(SecondsFormat::Secs, true),
            data: Some(data),
            errors: vec![],
        }
    }
}
```

In `lib.rs`, wrap every entry point with `std::panic::catch_unwind`, serialize to JSON, convert with `CString::new`, and return `into_raw()`. Implement free with `CString::from_raw(ptr as *mut c_char)` only for non-null pointers.

## Implementation Order Rationale

Tasks 1–4 establish a trusted local usage pipeline before any provider authentication complexity is introduced. Tasks 5–8 add quota one provider at a time behind a shared domain and only then expose aggregate bridge results. Tasks 9–11 establish Swift state and pure presentation logic before AppKit lifecycle work. Tasks 12–13 assemble the product surface only after core behavior is deterministic. Tasks 14–15 lock privacy/integration and distribution after functionality is complete, minimizing the chance that release plumbing hides correctness problems.
