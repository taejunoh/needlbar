Needlbar v0.3.15 changes where the Claude quota comes from. It no longer reads Claude Code's Keychain item or credentials file and no longer calls the usage endpoint, so Needlbar stops causing Keychain dialogs of its own.

- Needlbar now runs `/usage` through your installed Claude Code command-line tool and reads its usage report. The command is fixed and runs without a shell, in one fixed folder in the temporary directory that is emptied before each run, for at most 60 seconds, and Needlbar ends the process group it started afterwards. A process that moved to its own session or group is not covered. Its output is not logged or stored.
- Runs happen when Needlbar starts, when you choose **Check now** on the dashboard or in Settings, when a displayed window's reset passes, and after 15 minutes without a run. Automatic runs are in practice 15 minutes apart, and at least 5 minutes apart after a reset or a failed run. A change in Claude Code's local usage records does not start a run, because each run makes Claude Code scan its session transcripts from the last 7 days. Opening the dashboard does not start one. After repeated failures Needlbar waits 5, 10, 20, then 30 minutes.
- A window the report leaves out is hidden, never shown as zero. On accounts without a five-hour window, the quota shows the weekly windows.
- The Claude Code status line stays as the second source and last-known values as the third, labelled with the time they were checked. A newer valid reading wins whichever source it came from.
- Without Claude Code, Needlbar shows install guidance and the usage link. When Claude Code reports no usage, it says it could not check Claude Code and, if that continues, suggests running `claude` in Terminal to check its sign-in, then retries after a wait. It never runs `claude auth` or opens a login flow.

Known limits: usage, in Claude Code or outside it such as on the web, appears within about 15 minutes while Needlbar is running and the Mac is awake, or about 17 when a run is slow; **Check now** reads it at once. That means about 96 runs a day, plus runs after resets and retries after failures. A run takes longer as the session transcripts from the last 7 days grow: on one Mac the median run took about 8 seconds, and an earlier run used about 5 seconds of CPU and 454 MB of peak memory. A reading shows as last known after a failed run or once it is 20 minutes old. The usage report is marked experimental and can change, in which case Needlbar shows last-known values. API-key and usage-billed Claude Code sessions do not produce a usage report. Fable matching depends on a display label. Claude Code may renew its own login during a run, and `claude` itself may show a Keychain prompt. Native overnight, quota-reset, sustained unattended, and native macOS 14 acceptance remain unverified.
