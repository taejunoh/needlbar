Needlbar v0.3.10 fixes two process-handling reliability issues and hardens the build and test gates.

- The Claude Code status-line helper now forwards interrupt, terminate, and hang-up signals from before it starts the original status-line command, so stopping the helper during startup no longer leaves that command running.
- Manual repository analytics stops waiting on git output at its deadline, even when a git descendant process detaches from its process group while still holding the output pipes.
- The fail-closed widget dependency check now runs in CI with a pinned ripgrep instead of passing when the search tool is missing.
- Release builds on macOS 27 keep host-only Rust build units unstripped so macOS 27 can load the build's procedural macros; the shipped bridge keeps the same C exports.
- Release contract tests no longer depend on the shell locale, and process tests tolerate slow first launches of newly written executables under load.

Signals the helper does not forward (SIGKILL, SIGQUIT, SIGUSR1/SIGUSR2, and signals sent to the whole process group) can still leave the original command running, and a detached git descendant is not itself terminated. Credential renewal and cancellation of blocked synchronous calls are not implemented. Native overnight, quota-reset, and sustained unattended acceptance remain unverified.
