Needlbar v0.3.9 improves Claude quota freshness and refresh coordination.

- Source-aware freshness uses the actual successful observation time, preserves last-known values when that time is unknown, and keeps direct quota and Claude Code status-line evidence distinct.
- Wake and network recovery signals share refresh scheduling with periodic work, deduplicating overlapping attempts while preserving single-flight execution and user-request ordering.
- Generation checks fence lifecycle callbacks and local attempt diagnostics so stopped or restarted sessions cannot apply obsolete work.
- Open provider, Overview, dashboard, and Settings views age cached quota readings without extra provider requests or dashboard history samples.

Credential renewal and cancellation of blocked synchronous calls are not implemented. These changes do not establish recovery from expired credentials. Native overnight, quota-reset, and sustained unattended acceptance remain unverified.
