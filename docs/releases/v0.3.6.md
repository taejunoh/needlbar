Needlbar v0.3.6 presents Claude quota more compactly in the Overview.

- The Claude row shows the current remaining value when fresh, or the retained percentage labeled **Last known** when the current quota is unavailable.
- Source, failure reason, observation time, unavailable state, reset verification, and Fable's separate observation time are available in a default-collapsed **Quota details** disclosure. Fable keeps its independent status.
- Expanding or collapsing details preserves the existing dashboard layout behavior.

Quota refresh, authentication, and provider selection behavior are unchanged.
