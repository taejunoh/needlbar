Needlbar v0.3.7 adds read-only CPU, RAM, Disk, and Network information in Settings.

- CPU hardware and live utilization appear above the existing controls, with independently available hardware fields and explicit last-known or unavailable readings.
- RAM Used, Available, Total, Compressed, Wired, Swap, and OS pressure appear together. Compressed and Wired overlap the aggregate usage categories; they are not additional slices to add to Used. Pressure remains the OS classification, not the usage percentage.
- Disk shows root-volume capacity and backing-device read/write I/O. Capacity describes the system volume; I/O describes its backing device and is not volume-only activity.
- Network shows aggregate Network download/upload rates and reported interface names from the existing interface set, without implying that a reported name owns the aggregate traffic.
- Network Settings supports Dashboard-only, independently opted-in local and public IP display. Each existing option gates its own address immediately; IP values stay out of exports, widgets, notifications, logs, diagnostics, and provider requests.

The information cards reuse the existing snapshot stream on Menu bar, Dashboard, and Alerts tabs, independently of module visibility. IP rows appear only on Network's Dashboard tab. Successful sample times, **Last known**, zero, and unavailable values remain distinct.

Provider authentication and quota refresh behavior are unchanged. No extra collector or timer is introduced. This release adds no credentials, providers, updater, or analytics collection.

The supported distribution remains macOS 14 or later on Apple Silicon. Native macOS 14 arm64 acceptance remains pending external evidence. Local tests, packaging, and smoke checks do not establish Widget Gallery/App Group, notification-permission, VoiceOver, or full native interaction acceptance.
