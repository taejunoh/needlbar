Needlbar v0.3.5 adds an optional Claude Code status-line quota source.

- Claude Settings can explicitly connect the local Claude Code status line. The connection is off by default and does not add a quota polling request, login flow, or credential handling.
- When Claude Code emits a status-line update, Needlbar can display its five-hour and seven-day quota windows as **Reported by Claude Code**, with the local receipt time. The value is a received status-line report, not a timestamped provider fetch. The first value remains unavailable until Claude Code emits an update.
- Fable remains an independent direct-source value. It is not inferred from the status-line seven-day window and keeps its own freshness state.
This release adds no polling-based quota retrieval or automatic authentication renewal, and it does not guarantee future provider refresh availability.
